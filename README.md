# Cubitos Modpack

Chaotic, unbalanced, and buggy kitchen sink pack I put together with a friend. Has a mix of tech, food, and dimension mods. Probably uses 10 to 16 gigabytes of ram

now managed with [packwiz](https://github.com/packwiz/packwiz)!

## Notes

- I did not change `config/betternether` but BCLib requires its configs to be synced. I'm guessing a mod update changed a config's default and so the server now has "modified" that the client needs to reflect because i'm starting from defaults with packwiz and I haven't pushed to the server yet
